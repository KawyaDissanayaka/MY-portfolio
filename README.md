## 📖 About The Project

Welcome to my personal developer portfolio website! Built with modern web standards, this website presents my technical journey as a **Full Stack Developer** and **Computer Science Undergraduate**. It features a glassmorphism dark-themed aesthetic, smooth scrolling, interactive project cards, real-time GitHub integration, and a working contact interface.

### 🌟 Why This Portfolio Stands Out
- 🎨 **Sleek & Modern UI**: Tailored dark design tokens with custom radial glow backgrounds and glassmorphism.
- ⚡ **Lightweight & Fast**: Pure HTML5, CSS3, and vanilla JS with zero bulky dependencies.
- 📱 **Fully Responsive**: Optimized for desktops, tablets, and mobile devices.
- 📊 **Dynamic GitHub Stats**: Real-time stats and contribution chart integrated via GitHub API.

---

## ✨ Key Features

- **Hero Section**: Dynamic typing effect with direct action buttons (Resume download, Contact, Projects).
- **About & Strengths**: Core competencies, problem-solving skills, and personal developer philosophy.
- **Experience & Education**: Timeline detailing education at NSBM Green University and practical experience.
- **Skills Matrix**: Grouped by Programming Languages, Frameworks, Databases, and Tools.
- **Featured Projects Grid**: Interactive project cards with filter capabilities, pop-up details modal, and source code links.
- **Certifications Showcase**: Certificates with modal image view.
- **Live GitHub Statistics**: Repos count, followers, total stars, and contribution heatmaps.
- **Contact Form**: Interactive form with integrated direct mail/contact links.

## ⚡ Quick Start & Setup

Want to run or customize this portfolio locally? Follow these steps:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/KawyaDissanayaka/MY-portfolio.git
```

### 2️⃣ Navigate to project directory
```bash
cd MY-portfolio
```

### 3️⃣ Open in browser
Simply open `index.html` in your favorite web browser, or launch using **VS Code Live Server**:
```bash
# Using VS Code Live Server extension or python HTTP server:
python -m http.server 8000
```
Then visit `http://localhost:8000`.
